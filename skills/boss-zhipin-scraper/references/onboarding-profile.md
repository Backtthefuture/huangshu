# 首次引导、简历画像与偏好采集

## 首次引导

用户首次提出找工作、搜岗位或分析 BOSS 职位时，先说明流程：

> 我会先根据你的简历和求职偏好建立岗位画像，再去 BOSS 抽样读取一批真实 JD。分析后我会给出几档筛选和打招呼方案，由你选择后再进入触达阶段。第一步，请上传简历；支持图片、PDF、Word或粘贴文字。

提醒用户无需专门提供姓名、手机号和邮箱。不要要求其遮挡已经上传的材料，但不要主动回显无关个人信息。

## 无正式简历路径

没有正式简历时，引导用户提供：

1. 工作年限；
2. 最近岗位；
3. 主要项目及本人职责；
4. 有证据的技能和结果；
5. 学历。

信息不足时标记“未提供”，不要卡住整个流程。

## 画像字段

只提取：

- 工作年限；
- 最近岗位和目标线索；
- 行业经历；
- B端/C端、平台、工具或业务产品类型；
- 0到1、迭代、项目管理、团队管理；
- 量化结果；
- 工具、技术和方法；
- 学历；
- 可迁移能力；
- 简历未体现但目标岗位常见的能力。

将“已明确写出”“可迁移推断”“未体现”分开。可迁移推断只能作为分析，不能改写成用户已有经历。

## 两轮偏好采集

每轮最多问 3 个问题；已回答字段直接跳过。

第一轮：

1. 目标岗位，可附参考 JD；
2. 城市及是否接受远程；
3. 最低月薪。

第二轮：

1. 可接受的 JD 经验要求上限；
2. 必须排除项，如外派、驻场、纯销售、实习、兼职或单双休；
3. 可选偏好，如行业、公司规模、融资阶段和通勤区域。

必填：目标岗位、城市、最低薪资、经验上限和明确排除项。其余为选填。
